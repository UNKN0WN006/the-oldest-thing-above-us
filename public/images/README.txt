Background images
-----------------
stars.webp          tiled starfield used on the page background
earth-horizon.webp  Earth's edge, fixed to the bottom of every page
earth-globe.webp    globe on the loading screen (square, transparent corners)

These three were rendered by code, they are not photographs.
To use real photos, save your own files here with the SAME names. No code changes needed.

Free, public-domain NASA sources (check each image page for its credit line):
- NASA Visible Earth (visibleearth.nasa.gov): "Blue Marble" for the globe, "Black Marble" for city lights
- NASA Image and Video Library (images.nasa.gov): photos taken from the ISS, search "Earth limb" or "horizon"

Tips: keep each file under about 300 KB, and use .webp so phones load fast.
The horizon should be wide (about 2400 x 900) with a transparent sky.
